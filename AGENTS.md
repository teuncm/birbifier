# Birbifier

Welcome to the birbifier. The birbifier is inspired by zzfx, but smaller.

It's for the web, mobile-friendly and efficient. Make it use Tailwind. No extra AI text to fluff it up. Just the essentials.

Users are able to change a limited set of parameters, like:

- wave shape (square, sine, saw), speed, amplitude
- vibrato speed, amplitude
- tremolo speed, amplitude
- global low pass filter

Controls should be grouped (wave, vibrato, tremolo). Make this grouping apparent in the interface.

The user should be able to expand/collapse the controls such that all controls are visible expanded and only the values and locks are visible when contracted.

The vibrato and tremolo controls should include a LFO visualizer for intuitive parameter control. These should be centered about 0.

There should be a repeat button with a changeable pause duration.

Users are able to randomize all parameters with the click of a button. Parameters are lockable to prevent them from being changed by randomization.

Chirp duration is changeable from 0.5s to 5s. There is a download button to download the end result.

Create dropdown of nice presets. There should be 25 presets available. Users should also be able to browse through presets with left and right arrow buttons on the page, much like in vst synths.
